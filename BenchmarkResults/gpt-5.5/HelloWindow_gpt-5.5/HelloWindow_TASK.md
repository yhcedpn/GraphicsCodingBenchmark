# HelloWindow

## 目标

创建一个可运行的 Visual Studio C++ OpenGL 项目，打开一个窗口，并持续渲染，直到用户关闭它。

## 所需输出

将完成的项目放在当前目录下。

生成的项目必须是一个可运行的 Visual Studio C++ OpenGL 窗口示例，并使用：

- 目标 OpenGL `4.6`
- GLFW 用于窗口创建和事件处理
- GLAD 用于加载 OpenGL 函数

生成的程序必须创建一个满足以下结果的单一窗口：

- 窗口大小：`800 x 600`
- 窗口标题：`OpenGL HelloWindow Test`
- 窗口清除颜色：`0.2, 0.3, 0.8, 1.0`

## 约束

- **绝对禁止**以任何形式读取或写入或查找上级目录内的文件，包括调用工具和执行命令两种形式。
- 所有产物**必须**放在当前目录中，不可以在任何别处。
- 使用当前目录的 `vcpkg.json` 和 `vcpkg_installed/`。
- 不要修改 `vcpkg.json`、triplet、overlay 或共享的已安装树。
- 将所有生成的项目文件、源文件和构建输出都保留在该模型自己的结果目录中。

## 验收标准

- 可在 MSBuild 中以 `Debug|x64` 构建。
- 打开一个可见的、标题为 `OpenGL HelloWindow Test` 的窗口。
- 窗口以 `800 x 600` 的大小打开。
- 使用颜色 `0.2, 0.3, 0.8, 1.0` 清空窗口。
- 按下 `Esc` 可关闭窗口。
- 使用 GLFW 和 GLAD，并以 OpenGL `4.6` 为目标。
