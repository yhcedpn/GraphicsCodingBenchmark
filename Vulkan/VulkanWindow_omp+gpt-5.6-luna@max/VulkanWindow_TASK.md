# VulkanWindow

## 目标

在当前项目中实现一个可运行的 C++ Vulkan 程序：创建单一可见窗口，并持续渲染，直到用户关闭窗口。

## 可用依赖

使用当前项目已配置的依赖集合，不新增第三方依赖：

- GLFW
- Vulkan
- volk
- Vulkan Memory Allocator
- Vulkan Utility Libraries
- shaderc
- SPIRV-Tools
- SPIRV-Reflect

使用 GLFW 创建窗口、处理事件并建立 Vulkan Surface；具体渲染结构和着色器方案自行选择，不得假定特定操作系统、IDE 或编译器。

## 画面要求

窗口客户区必须完全由四个纯色区域覆盖，分界线位于水平与垂直中心：

- 左上：红色，RGBA `(1.0, 0.0, 0.0, 1.0)`
- 左下：白色，RGBA `(1.0, 1.0, 1.0, 1.0)`
- 右下：蓝色，RGBA `(0.0, 0.0, 1.0, 1.0)`
- 右上：绿色，RGBA `(0.0, 1.0, 0.0, 1.0)`

颜色必须由 Vulkan 渲染并呈现；不得用多个子窗口、控件或静态图片拼接结果。

## 约束

- 所有修改和生成物仅限当前目录，不读取、查找或写入上级目录。
- 使用当前项目已有的依赖声明和构建配置，不修改共享配置或已安装依赖树。
- 正确处理窗口事件、交换链失效以及窗口尺寸变化；窗口关闭后正常释放 Vulkan 资源并退出。
- 不允许以硬编码截图、预生成帧或软件窗口绘制冒充 Vulkan 渲染。

## 验收标准

- 项目可使用当前环境提供的构建入口完成配置与构建。
- 程序启动后出现单一可见窗口，且保持响应。
- 实际呈现画面的位置、颜色和覆盖范围符合上述四象限要求。
- 调整窗口大小后仍满足四象限布局，不出现未覆盖区域或明显错位。
- 关闭窗口后程序正常退出。
